# Mannequin and 3D clothes

`my-ecommerce-store/public/models/mannequin.glb` is generated by this folder. It holds:

- **Body**: a glossy black display mannequin with a smooth, faceless egg head, built from MakeHuman's base mesh with young-male, slim and ideal-proportion shape targets applied, 1.86 m tall.
- **Skeleton**: MakeHuman's default rig, reduced to 74 bones (face bones folded into the head, toes into the feet). Rest pose is an A-pose.
- **Clothes**, all skinned to the same skeleton so they follow every pose:
  - Hoodie: drape, ribbed hem and cuffs, rolled hood, kangaroo pocket, drawstrings.
  - Tee: ribbed collar.
  - Cargo trousers: waistband, cargo pockets with flaps.
  - Cap: brim and button.
  - Sneakers: lofted around the foot, with sole, stripe, collar and laces.

## Source assets

MakeHuman (https://github.com/makehumancommunity/makehuman), folder `makehuman/data`. Its assets (base mesh, targets, skeleton, weights) are released under **CC0**: free for commercial use, no attribution required.

Files used:

```
3dobjs/base.obj
rigs/default.mhskel
rigs/default_weights.mhw
targets/macrodetails/{african,asian,caucasian}-male-young.target
targets/macrodetails/universal-male-young-averagemuscle-minweight.target
targets/macrodetails/height/male-young-averagemuscle-averageweight-maxheight.target
targets/macrodetails/proportions/male-young-averagemuscle-averageweight-idealproportions.target
```

## Rebuild

```bash
tools/mannequin/build.sh /path/to/makehuman/makehuman/data
```

This runs `build-mannequin.mjs` (body, rig, clothes → GLB) and then `gltfpack` (mesh compression, about 1.6 MB → 0.37 MB). The storefront decodes it with the Meshopt decoder that drei's `useGLTF` loads.

Garment shapes live in `garments.mjs`. Each garment chooses a region of the body, pushes it out by a fabric allowance, drapes it over hollows, and cuts clean hems along planes. Pocket patches, the hood, the brim, laces and collars are extra parts that take their skin weights from the nearest body vertex.

## Product images

The demo catalog's product images are renders of these 3D garments:

```bash
cd my-ecommerce-store && npx vite --port 5180      # in one terminal
node tools/render-thumbnails.cjs http://127.0.0.1:5180
```

This writes `my-ecommerce-store/public/demo/products/<product id>-<color>.webp`.
